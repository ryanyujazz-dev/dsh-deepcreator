# Bundle packages

`deepcreator-web` is the user-facing composition unit. Its patch disables official UI owners that DeepCreator replaces and inserts the matching DeepCreator Client plugins under distinct row ids. Official Runtime, transport, Slot rendering, and unchanged feature rows remain active.

The same bundle also composes the optional-by-setting trusted-LAN HTTP `remote-access` Host gateway and `ui-remote-access` Settings contribution. Remote browsers receive the identical Client plugin tree; responsive layout and capability gates adapt that tree without a second mobile UI, certificate flow, or Service Worker.
