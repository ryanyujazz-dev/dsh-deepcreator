# DeepCreator Review Service

Scoped Review and per-turn change history for Workbench. In Git workspaces the default `uncommitted` scope is `HEAD → worktree`; before a repository has its first commit, Git's empty tree replaces `HEAD`. `unstaged` (`index → worktree`), `staged` (`HEAD → index`), and `{ turn }` (turn start → live/end snapshot) are also available. A non-Git workspace exposes current and completed Turn scopes only. Per-file results carry unified patches and full source snapshots, including renames, deletes, untracked files, binaries, and symlinks.

`status(session, scope)` returns the file list without loading source snapshots. The backward-compatible `summary(session, scope)` computes range-wide `--numstat` once and returns per-file additions, deletions, and binary state independently, so large Review lists can paint every header before requesting any heavy body. Older clients and Hosts may continue using `diff` alone.

Worktree snapshots are captured at official turn boundaries: start before the first `agent/pre-step`, end at awaited `agent/turn-stopping`, with `turn/end` as fallback. A temporary index writes Git trees without touching the real branch, index, or worktree. Open turns compare the retained start tree with the live worktree, so mutation links can reveal a Diff before the turn ends. Git workspaces anchor synthetic commits under `refs/deepcreator/turns/{sessionId}/{turn}`; non-Git workspaces use a session-private bare object database under DSH home, exclude that private state if the workspace contains it, and never create a project `.git`. Commit reconciliation remains Git-only, conservative, and per file; a fully committed turn is removed immediately, while non-Git completed turns remain available as history.

`undoTurn` is the only mutation. It accepts only the newest unresolved turn, computes reverse three-way candidates for both index and worktree in temporary Git trees, rechecks HEAD/index/worktree for races, and only then applies the prepared result. Conflicts and stale state reject the whole operation, preserving later manual edits and preventing partial undo. No stage, unstage, or commit UI is provided.
